# python-object-type-identification
A simple Python OOP program demonstrating how to identify the class of different objects using the built-in type() function and the __name__ attribute.
<br>
Topics Covered:
<br>

1. Classes and Objects – Defining classes and creating instances.
2. type() Function – Identifying an object's class at runtime.
3. __name__ Attribute – Retrieving the class name as a string.
4. Object Instantiation – Creating objects using class constructors.
5. Runtime Type Identification – Determining object types while a program executes.
6. Python OOP Fundamentals – Understanding relationships between classes and objects.
